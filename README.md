# Cricket Legends Game — Brain Rehab Edition

A cricket-themed memory & trivia game designed for cognitive rehabilitation.

## Features
- ✅ 5 Levels (Easy → Legend)
- ✅ Card-matching memory & trivia rounds
- ✅ Real-time scoring & streaks
- ✅ Timer tracking for speed monitoring
- ✅ Milestones & celebrations
- ✅ Mobile-friendly design
- ✅ Accessible fonts & large tap targets

## How to Play

1. **Choose a Level** (1-5)
2. **Memory Round:** Flip cards to match pairs
3. **Trivia Round:** Match questions with answers
4. **Earn Points:** Each match = 75 points
5. **Unlock Milestones:** As you score higher
